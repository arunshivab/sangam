संSangam — Visual Mockups

Working visual designs for the auth flow, self-service portal, and admin UI. Using LiPi as the example partner application. These are intentionally separate aesthetics — LiPi is editorial and script-literary, Sangam is quiet authority. The contrast itself teaches users where they are.

DPDPA defensibility: This screen names the specific app, lists specific data types, names the user's actual data values, explicitly states what won't be shared, and offers a revocation path. When a regulator asks "did the user know what they consented to?" this screen is the answer.

The dark sidebar is deliberate. Admin UIs that look identical to user UIs lead to operators forgetting which mode they're in. The contrast makes "I am an admin right now" a constant subconscious signal. Operators do destructive things in admin UIs; the interface should reflect that gravity.
