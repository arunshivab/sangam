# OWASP ASVS 4.0.3 Level 2 self-assessment

Sangam v1.0.0-rc.1 (R7), updated for v1.0.0-rc.2. This is an internal self-assessment, not a certification and not a substitute for the external penetration test (see [pentest-scope.md](pentest-scope.md)). Every one of the 259 Level 2 requirements has a status, the evidence that supports it, and a note.

## How it was done

- Four independent review passes read the code at the R7 working tree (chapters V1 and V14; V2 and V3; V4, V5, V12 and V13; V6 to V11) and recorded a status for each requirement with file and line citations. The passes did not write code.
- The findings were then fixed where a fix was in scope for R7 (column *Updated*: “R7 fix”), with a test for each; the remaining gaps are recorded as founder decisions or open items (SGM-701, SGM-908).
- Citations are re-anchored to the R7 tree. A citation is `path:line — what it shows`; tests are named by method. Line numbers are a guide (code moves); the description names the code.
- Dynamic evidence: OWASP ZAP baseline and authenticated full scans of all four hosts before and after the fixes ([zap.md](zap.md)); dependency and container scans ([dependency-scan.md](dependency-scan.md)).

Statuses: **Met** — the requirement is satisfied by the code or configuration cited. **Partly** — some of it is; the note says what is missing. **Not met** — it is not. **Founder** — it needs a decision, a policy or an operational record only the founder can provide (a written SDLC, a key-management policy, a hosting control, or accepting a deviation). **N/A** — it does not apply to Sangam (the note says why).
